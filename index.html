METODOLOGIA PEDAGÓGICA

Como usar em sala de aula

A plataforma foi desenhada especificamente para facilitar o momento de ensino e aprendizagem com projetor ou lousa interativa.

1. Modo Projeção

Clique no botão "Projeção" no canto superior de qualquer laboratório para expandir em tela cheia na lousa digital ou retroprojetor com alto contraste.

2. Pergunta Disparadora

Use a caixa "Pergunta para investigar" antes de revelar a teoria. Provoque os alunos a deduzirem o teorema através da manipulação dos vértices.

3. Honestidade Numérica

Os algoritmos aplicam compensação aritmética em tempo real para garantir que identidades como α + β + γ = 180° e sen² + cos² = 1 nunca apresentem resíduos de arredondamento confusos.

4. Uso Offline & GitHub Pages

Baixe o pacote completo em ZIP para abrir em qualquer computador sem internet ou hospede 100% grátis no GitHub Pages.
