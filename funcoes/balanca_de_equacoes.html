FUNDAMENTAÇÃO ÁLGEBRICA

Entenda a Ideia

Uma equação não é uma conta para “fazer”; é uma declaração de igualdade, assim como dois pratos de uma balança em equilíbrio perfeito.

A = B  ⟺  A ± c = B ± c
A · c = B · c  |  A ÷ c = B ÷ c  (c ≠ 0)
Princípio Fundamental da Equivalência: "O que você faz de um lado da balança, deve OBRIGATORIAMENTE fazer do outro lado para não quebrar o equilíbrio."
1
A Balança e o Fiel O sinal de igualdade ($=$) é o ponto de equilíbrio no centro. Se um prato tiver mais peso, o fiel inclina imediatamente para o lado mais pesado.
2
O Pacote Misterioso $x$ Todas as caixas com etiqueta x guardam exatamente a mesma quantidade de unidades. Nosso objetivo ao resolver a equação é deixar uma única caixa $x$ sozinha em um prato e todos os pesos no outro.
3
Operações Inversas Simétricas Quando alguém diz na sala de aula que "o termo passa para o outro lado trocando de sinal", o que realmente está acontecendo é a retirada ou soma do mesmo valor nos dois pratos ao mesmo tempo!
4
A Divisão Final Se no final sobram $3$ caixas iguais a $12$ pesos ($3x = 12$), dividimos os dois pratos por $3$. Cada caixa $x$ conterá exatamente $4$ pesos ($x = 4$).
Pergunta para Investigar

Monte a equação x + 7 = 12. Retire 1 peso unitário do prato esquerdo. O que aconteceu com o fiel? Agora retire 1 peso do prato direito também. O fiel voltou ao centro?

Se você retirar os 6 pesos restantes de cada lado, qual é o valor que sobra para o pacote x? E se tivéssemos retirado pesos de um lado só, o resultado continuaria verdadeiro?
