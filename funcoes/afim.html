Forma Geral da Função Afim
f(x) = ax + b
1
Coeficiente Angular (a): É a taxa de variação ou inclinação (Δy / Δx). Se a > 0, a reta é crescente; se a < 0, a reta é decrescente; e se a = 0, a reta fica totalmente horizontal (função constante).
2
Coeficiente Linear (b): É o ponto exato onde a reta corta o eixo vertical Y, ou seja, o ponto (0, b). Quando b = 0, a reta cruza exatamente na origem (0,0).
3
Raiz ou Zero da Função: É o ponto onde y = 0, obtido resolvendo ax + b = 0 ⇒ x = -b/a (quando a ≠ 0). É onde a reta intercepta o eixo horizontal X.
Pergunta para investigar

O que acontece com a inclinação da reta quando a fica negativo? E quando a = 0, o que acontece com a raiz da função e com a dependência da variável x?
