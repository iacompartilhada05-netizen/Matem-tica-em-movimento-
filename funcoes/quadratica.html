Entenda a ideia

Como os elementos algébricos da equação definem os pontos geométricos da parábola.

Equação Geral e Discriminante
y = ax² + bx + c  |  Δ = b² - 4ac
1
Concavidade (a): Se a > 0, a parábola tem concavidade voltada para cima e possui um ponto de mínimo. Se a < 0, a concavidade é para baixo e possui um ponto de máximo.
2
O Vértice V(xᵥ, yᵥ): É o ponto de inflexão da curva, com xᵥ = -b / (2a) e yᵥ = -Δ / (4a). O eixo vertical pontilhado que passa por xᵥ é o eixo de simetria bilateral da parábola.
3
O Discriminante (Δ): Se Δ > 0, a curva cruza o eixo X em duas raízes distintas. Se Δ = 0, o vértice toca tangencialmente o eixo em uma raiz única dupla. Se Δ < 0, a parábola não toca o eixo X.
Pergunta para investigar

Como a alteração do valor de c afeta a parábola sem alterar seu formato nem o seu eixo vertical de simetria? O que acontece com as raízes quando você sobe ou desce o valor de c?
